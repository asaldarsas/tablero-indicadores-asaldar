Hojas utilizadas

Trazabilidad del archivo

Este HTML se alimentó con las hojas INFO CONCILIADORAS, GRAFICOS CONCILIADORAS y el indicador corporativo de FICHA TÉCNICA. La información fue normalizada en registros por año, mes, entidad o equipo, métrica, meta y recaudo o cantidad real según corresponda.

Recomendación de organización

Modelo para crecer hasta 2030

Para mantener el tablero sano, la base debe crecer en formato largo: una fila por mes, conciliadora y métrica. Así se evita crear hojas nuevas por cada año y se pueden agregar años hasta 2030 sin rediseñar el HTML ni cambiar la estructura de JSONBin.

Estructura recomendada:
Año · Entidad/equipo · Mes · Responsable · Métrica · Tipo de cartera/indicador · Meta · Recaudo / cantidad · Asignado · Cumplimiento automático
